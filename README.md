# ☁️ CloudDrop — хмарний сервіс обміну файлами

Проєкт з дисципліни «Хмарні та Grid технології».

Вебсервіс, де користувач завантажує файл і отримує посилання, щоб поділитися ним.
Застосунок працює на Linux-сервері в **Microsoft Azure**, файли зберігаються в **Azure Blob Storage**,
а оновлення автоматично розгортаються через **GitHub Actions**.

## Технології

| Шар | Технологія | Модель хмари |
|---|---|---|
| Сервер | Azure Virtual Machine, Ubuntu 24.04 | IaaS |
| Сховище файлів | Azure Blob Storage | PaaS |
| Мережа | Virtual Network, Network Security Group | IaaS |
| Моніторинг | Azure Monitor + алерт на пошту | PaaS |
| Застосунок | Python 3.12, Flask, Gunicorn | — |
| Контейнеризація | Docker, Docker Compose | — |
| Вебсервер / проксі | Nginx | — |
| CI/CD | GitHub Actions (тести → деплой) | — |

## Структура проєкту

```
clouddrop/
├── app/                    # застосунок
│   ├── app.py              # бекенд (Flask)
│   ├── templates/          # HTML-сторінки
│   ├── requirements.txt
│   └── Dockerfile
├── nginx/nginx.conf        # реверс-проксі
├── docker-compose.yml      # запуск app + nginx
├── tests/test_app.py       # автотести
├── scripts/
│   ├── azure-create.sh     # створює всю інфраструктуру в Azure
│   └── setup-vm.sh         # встановлює Docker на сервер
├── .github/workflows/deploy.yml   # CI/CD
├── .env.example
└── docs/                   # схема архітектури, план презентації
```


## Що вміє застосунок

- Завантаження файлів до 50 МБ
- Коротке посилання виду `http://IP/f/AbC123xy`
- Файли зберігаються в Azure Blob Storage, а посилання на скачування тимчасове (SAS-токен, 24 год)
- Сторінка `/health` для моніторингу
- Автотести, які запускаються перед кожним деплоєм

## Безпека

- Вхід на сервер тільки по SSH-ключу, вхід за паролем вимкнено
- Відкриті тільки порти 80 і 22 (NSG в Azure + ufw на сервері)
- Контейнер застосунку працює не від root
- Публічний доступ до сховища вимкнено, файли віддаються лише через тимчасові SAS-посилання
- Ключ до сховища зберігається в `.env` на сервері, а ключ SSH у GitHub Secrets; у коді секретів немає
